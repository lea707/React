# React Learning Project

A React app built while learning frontend development fundamentals.

## What's included

- React Router — multi-page navigation
- Full CRUD operations — GET, POST, PUT, DELETE with JSONPlaceholder API
- Custom hook — useFetch for reusable data fetching
- useContext — role-based user switching
- Search and filter — real-time filtering on Posts and Users pages
- Loading and error states — proper async handling

## Pages

- **Home** — landing page with user context display
- **Users** — fetches and displays users with search
- **Posts** — fetches posts with search, edit, and delete
- **New Post** — form to create a new post via POST request

## Tech Stack

- React 18
- React Router DOM
- Vite
- JSONPlaceholder API (mock REST API)

## Running locally

```bash
npm install
npm run dev
```
